## Scope and size evidence

Compared with harness base `5fd45f3`, the scout reference goes from **9,357 to 5,389 Unicode characters (42.4% fewer)**. It retains read-only authority, no helper launches, user-change protection, domain checks, specialist routing, test-evidence limits and an actionable worker brief. This saves reference text only when the guide is read; agents that previously read selected sections may see different results.

The unconditional Pi `CORE_GUIDANCE` grows from **6,419 to 6,620 JavaScript string code units (+201)**. Its duplicate untrusted-content instruction was removed while the dedicated section remains. Copilot's child context is **2,401 code units** at `/workspace/agent-harness`; the existing long-install-path test verifies its 2,500-character budget. No provider token counts, cache billing or task-quality measurements were taken. Do not add these character reductions to the README's simulated token/cost savings.

Only instructions and reference text change. Prompt guidance does not prove model compliance, enforce account isolation, or redact tool output. Existing host guards and permission boundaries remain authoritative. No request-shaping algorithm, mandatory review stage or new runtime dependency is introduced.
