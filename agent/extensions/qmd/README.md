# Plain QMD Pi extension

index.ts registers qmd_search, qmd_get and qmd_status. Code subagents load it explicitly. Runtime discovery matches the QMD shell skill: `HARNESS_QMD_CLI`, then this extension's `config.json`, then `PI_CODING_AGENT_DIR/extensions/qmd/config.json` (default `~/.pi/agent`), then the global `npm install -g @tobilu/qmd`. A checkout-local config is optional. Discovery happens on the first lookup, so missing QMD does not prevent the extension from loading; that lookup returns an actionable error.

For an isolated installation, set `HARNESS_QMD_CLI` to the absolute `@tobilu/qmd/dist/cli/qmd.js` path. Optional overrides are `HARNESS_QMD_NODE`, `HARNESS_QMD_INDEX` and `HARNESS_QMD_TIMEOUT_MS`. Build your collections separately; installation alone does not create an index.

Search uses BM25 with three hits by default (maximum five), an optional collection scope, and no returned snippets. Get reads a selected document range (at most 100 lines) and shows a 10000-character preview. Status inspects existing collections. No LLM expansion, reranking, adaptive learning or index setup/update/embed tools are exposed. CLI arguments are passed without a shell.

## Output beyond 10000 characters

qmd_get and qmd_status keep the 10000 UTF-16-character limit for preview plus notice together (not bytes, not the SDK's 50KB). Output at or under the limit is returned unchanged with no file I/O. When successful stdout is longer, the exact stdout received from the QMD CLI for the requested range (not the whole document, and still under the existing 256000-character stdout guard) is saved as UTF-8 to a new random file `pi-qmd-<16 hex>.txt` in `os.tmpdir()` (so TEMP/TMP/TMPDIR apply, read per call). The notice names the file; `read` with the advertised offset pages it (offsets count lines of the saved file, not of the source document). If any line is over 50000 bytes, the notice also gives a single-quoted `bash` command running the Node that is running Pi (`'<node>' -e '<script>' '<path>' <offset>`) because `read` cannot page such a line. Each run prints one JSON line `{start,next,total,text}` of at most about 40000 bytes: `text` is JSON-escaped (CR, control characters, ESC and U+2028/9 are escaped, never dropped, since the SDK bash tool decodes each command's output on its own and strips/rewrites those), chunks end on code point boundaries, and `start`/`next`/`total` are UTF-16 offsets in the saved file (not the source document). Re-run with `next` as the last argument until it is null. The earlier `tail -c`/`head -c` recipe was dropped because a 50000-byte cut can split a multibyte character and each command's output is decoded separately, so that character was lost to the model.

Limits:
- Recovery needs the `read` tool active (and `bash` plus a verified Node runtime when a line exceeds 50000 bytes; the runtime is the running interpreter's `process.execPath`, accepted only if it is an absolute `node`/`node.exe` path outside Bun, with no probe spawned, so a standalone Pi binary gets the unavailable notice). Without them, if the active-tool lookup throws, if the output has lone surrogates, or if the temp path is unsafe or the write, close or size check fails, the successful result is kept with a capped-output notice that says the rest was not retained and names no file. QMD is never re-run, and real QMD errors and the stdout guard are unchanged.
- Files are created exclusively (`wx`); one EEXIST retry with a new name, never an overwrite. A failed or partial file is left in place, never deleted or advertised. There is no automatic cleanup or rotation: files live until the OS or user removes them, so they are not durable storage.
- POSIX files are mode 0600 (subject to umask). On Windows the mode only affects the read-only attribute; the file inherits the temp directory's ACL.
- Applies wherever this shared extension is loaded (main session and code subagents that load it). The saved text is only what the model was already shown access to. Frequency and any context saving are unmeasured; this recovers a previously silent cut, it is not a measured cost reduction.

Edit config.json if your Node or QMD installation moves. Restart Pi or use /reload. Existing QMD collections and database are preserved.
